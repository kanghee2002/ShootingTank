## 플랫포머 슈팅 게임
- 2024.02 ~ 2024.09
- 개인 프로젝트
- Unity, Windows
## 주요 기능
- 상속과 오버라이딩을 이용한 다양한 무기와 적 구현
- NxN 플랫포머 맵 생성 알고리즘
- Collider를 이용한 적 시야각
- State machine, Raycast를 이용한 적 AI 움직임
- 오브젝트 풀링을 이용한 총알 최적화

## 의미
**군 제대 전 남는 시간을 활용해** 개발에 돌입했습니다. 이전 경험을 발전시켜, 시야각 구현과 더불어 State machine, Raycast를 활용한 자연스러운 적 AI를 구현했습니다. NxN 모양의 스테이지 생성 알고리즘을 구현하고, 총알 오브젝트 풀링을 이용해 최적화했습니다. 상속과 오버라이딩으로 다양한 무기와 적을 구현하며 확장 가능한 구조를 만들었습니다.
 하지만, 이 과정에서 복잡한 상속 구조가 오히려 코드의 확장성과 가독성을 떨어뜨릴 수 있다는 점을 직접 경험했습니다. 그렇기에 **필요한 기능을 적재적소에 사용하는 설계의 중요성**을 깨달았고 이후, Soul Chess 프로젝트에서는 **상속 구조를 개선하여 적용해보는 성장**을 이뤄낼 수 있었습니다.
